# Annotation Activity Console

A production-ready real-time annotation dashboard built with Next.js, Express.js, MongoDB, Socket.IO, and Redux Toolkit.

## Features

- Real-time task updates using Socket.IO
- Task management with CRUD operations
- JWT Authentication
- Redux Toolkit state management
- MongoDB Atlas integration
- IndexedDB offline caching
- Server-Sent Events (SSE)
- Secure Markdown rendering
- Responsive dashboard
- Filtering, sorting, searching, and pagination

## Tech Stack

### Frontend
- Next.js 14
- React 18
- TypeScript
- Redux Toolkit
- Tailwind CSS

### Backend
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JWT Authentication
